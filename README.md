# ustaz.pro LEGO — тестовые выпуски

[Скачать единый установщик](https://github.com/Ruslando123/ustaz-pro-suite-releases/releases/latest/download/UstazProLego-setup.exe) · [Версии и изменения](https://github.com/Ruslando123/ustaz-pro-suite-releases/releases)

## Установка

1. Сохраните презентации и закройте PowerPoint и главное окно LEGO.
2. Скачайте `UstazProLego-setup.exe` по ссылке выше и запустите его.
3. Откройте LEGO. Вход в этом тестовом выпуске использует демонстрационные аккаунты.

Требуются Windows x64, PowerPoint x64 и .NET Framework 4.8. Установщик включает приложение, надстройку и локальную тестовую площадку; SDK .NET для тестировщика не нужен.

## Обновления

При запуске приложение проверяет общий тестовый канал. Если опубликована версия новее установленной, появляется окно с описанием изменений и кнопкой «Обновить сейчас».

Перед установкой обновления сохраните работу и закройте PowerPoint. Если установлена последняя версия, окно обновления не появляется. После первого выпуска новые обновления будут появляться по мере их публикации в канале.

## Что проверить

- Установка и появление надстройки в PowerPoint.
- Вход после выбора демонстрационного аккаунта.
- Создание, сохранение и повторное открытие авторского проекта.
- Предварительный просмотр модулей.
- Обновление на следующий опубликованный выпуск.

При переносе авторского проекта передавайте презентацию вместе с её папкой `<имя>.ustaz`.

В этом репозитории находятся установщики и сведения об обновлениях. Исходники приложения здесь не размещаются.
